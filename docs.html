البدء واستخدام النظام

صحصح بيجمع عمليات البيع والمخزون والعملاء والحسابات في منظومة واحدة. ابدأ من الوحدة المناسبة لخطوة الشغل، والنظام بيربط البيانات بين الوحدات المفعلة لحسابك.

١. اختار الوحدةافتح المبيعات أو المخزون أو أي وحدة متاحة حسب صلاحيتك.
٢. سجّل العمليةأدخل بيانات العملية مرة واحدة، مثل الفاتورة أو الاستلام أو المصروف.
٣. راجع أثرهاتابع تحديث رصيد الصنف أو حساب العميل أو الخزينة والتقارير المرتبطة.
قد تختلف الشاشات والتفاصيل حسب إعداد الحساب والوحدات والصلاحيات المفعلة.

المبيعات والفواتير

تبدأ دورة البيع بعرض سعر أو أمر بيع، ثم تسجيل الفاتورة والتحصيل وربط العملية بحساب العميل.

  1. أنشئ عرض سعر أو أمر بيع وحدد العميل والأصناف والكميات.
  2. حوّل العملية إلى فاتورة بيع عند تأكيدها.
  3. سجّل المبلغ المستلم وطريقة السداد: نقدي أو بنكي أو آجل.
  4. راجع الفاتورة وحركة العميل والمخزون والخزينة.

نقطة البيع

استخدم شاشة نقطة البيع لتسجيل البيع بسرعة ومراجعة حركة الكاشير والورديات.

  • ابحث عن الصنف أو امسح الباركود.
  • أضف الأصناف إلى الفاتورة وحدد طريقة السداد، بما فيها السداد المجزأ عند توفره.
  • علّق الفاتورة للرجوع إليها أو استرجع فاتورة معلقة.
  • تابع عمليات الكاشير والوردية من شاشة إدارة نقطة البيع.

المخزون والفروع

تابع أرصدة الأصناف وحركتها بين المخازن والفروع، وسجّل الجرد والتسويات.

  • راجع رصيد الصنف وحركته في كل مخزن.
  • نفّذ الجرد وسجّل التسوية عند وجود فرق.
  • استخدم تحويلات المخزون لنقل البضاعة بين الفروع.
  • تابع تنبيهات حد إعادة الطلب لتحديد الأصناف التي تحتاج إلى توريد.
تحديث الرصيد يعتمد على إعدادات المخازن وطريقة تسجيل البيع والاستلام في حسابك.

المشتريات والموردون

اربط طلبات الشراء وفواتير الموردين باستلام البضاعة ومستحقات المورد.

  1. سجّل طلب الشراء والأصناف المطلوبة.
  2. أضف فاتورة المورد عند وصولها.
  3. أكد استلام البضاعة لتحديث المخزون.
  4. راجع مستحقات المورد وحركة التعاملات والمدفوعات.

العملاء والتحصيل

ملف العميل يجمع بياناته وسجل التواصل والمشتريات والدفعات وكشوف الحساب.

  • افتح ملف العميل لمراجعة الفواتير والمعاملات السابقة.
  • تابع المديونية والدفعات المسجلة.
  • سجّل التحصيل واربطه بالفاتورة أو حساب العميل حسب الإجراء المتاح.
  • استخدم كشف الحساب لمراجعة الحركة.

الخزينة والحسابات

تابع حركة النقدية والحسابات البنكية والمصروفات والقيود المرتبطة بعمليات النظام.

  • سجّل المصروف على الخزينة أو الحساب المناسب.
  • راجع أرصدة الخزائن والحسابات البنكية والشيكات.
  • طابق المبيعات بالمبالغ المستلمة.
  • استخدم تقارير الإيرادات والمصروفات والقوائم المالية المتاحة.

التقارير والتحليلات

استخدم التقارير لمراجعة الأداء وحركة الأصناف والنتائج المالية، مع مؤشرات الأداء المتاحة في حسابك.

  • حدد التقرير والفترة أو الفرع المطلوب مراجعته.
  • قارن المبيعات وحركة الأصناف والنتائج.
  • صدّر التقرير إلى Excel أو PDF إذا كان التصدير متاحاً في الشاشة.

المستخدمون والصلاحيات

إدارة المستخدمين والأدوار تساعد على تنظيم الوصول للوحدات والعمليات حسب مسؤولية كل فرد.

  • أنشئ حساب المستخدم وحدد دوره.
  • راجع الصلاحيات الممنوحة للوحدات والعمليات.
  • استخدم سجل المراقبة لمتابعة التعديلات إذا كان مفعلاً لحسابك.
